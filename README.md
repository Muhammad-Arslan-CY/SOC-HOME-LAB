# Cybersecurity Lab

A personal, hands-on cybersecurity lab for building practical skills through experimentation, investigation, documentation, and continuous learning.

## Purpose

This repository documents my cybersecurity learning journey and practical lab work.

It serves as a long-term record of:

* Hands-on security experiments
* SOC and SIEM activities
* Security investigations
* Lab infrastructure
* Tools and technologies
* Lessons learned
* Evidence and observations

## Current Focus

* Wazuh SIEM
* SOC fundamentals
* Security monitoring
* Alert investigation
* Incident response
* Linux and Windows security
* Virtualized lab infrastructure

## Lab Environment

Current lab components include:

* Ubuntu Server
* Kali Linux
* Windows host
* Wazuh
* VirtualBox

## Documentation

Daily work, experiments, evidence, and lessons learned are documented chronologically within the repository.

The repository will grow organically as new technologies, tools, and security capabilities are added to the lab.

Sensitive information such as passwords, private keys, API keys, tokens, credentials, and other secrets must never be committed to the repository.
