# Day 1 — Lab & Wazuh Setup

**Date:** 2026-08-06

## Completed

* Set up the virtualized lab environment in VirtualBox.
* Configured Ubuntu Server and Kali Linux VMs.
* Configured NAT, Host-Only, and internal networking as required.
* Set up Windows ↔ Ubuntu SSH access.
* Installed Docker Desktop and configured WSL 2 / VirtualMachinePlatform.
* Deployed Wazuh 4.14.x single-node stack with Docker.
* Configured Wazuh Manager, Indexer, and Dashboard.
* Connected Ubuntu Server as a Wazuh agent.
* Verified the agent as active in the Wazuh Dashboard.
* Configured Apache on Ubuntu for additional telemetry.
* Generated controlled SSH authentication events.
* Generated repeated Apache HTTP requests from Windows.
* Verified the resulting activity in Ubuntu logs and Wazuh.

## Key Learning

* Virtual machine networking and host-to-VM communication.
* Wazuh deployment and basic component architecture.
* Agent connectivity and security telemetry.
* Using system/application activity to generate observable security events.

## Result

A functional virtualized SOC lab was established with Windows, Ubuntu Server, Kali Linux, and Wazuh, ready for security monitoring and controlled testing.
