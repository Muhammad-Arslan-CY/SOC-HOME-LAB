# Work of the Day — NIDS Telemetry Integration & Perimeter Security Incident Investigation

## Overview

Today’s focus was establishing an end-to-end network telemetry pipeline using **pfSense (Suricata NIDS) + Ubuntu Syslog Relay + Wazuh SIEM**, followed by a full **SOC Level 10 incident investigation, triage, and escalation**.

---

## 1. Network Telemetry Pipeline

* Configured pfSense to forward remote system logs and Suricata NIDS telemetry via UDP 514.
* Used the Ubuntu Server as an intermediate Rsyslog collector to bypass Docker UDP proxy limitations, relaying perimeter events securely over TCP 1514 via the Wazuh Agent (`Agent 002`).
* Validated bidirectional telemetry ingestion from the firewall and IDS directly into Wazuh.

---

## 2. Security Activity Simulation

* Executed targeted reconnaissance and SYN/ACK port scanning from Kali Linux (`192.168.20.10`) against internal assets (`192.168.10.10`) across pfSense.
* Observed concurrent live telemetry generation:
  * **Suricata NIDS:** Protocol anomalies and ICMP decode events.
  * **pfSense Firewall:** Repeated TCP packet filter drop events (`filterlog`).

---

## 3. Incident Response Activity (Activity 03)

Investigated a critical **Level 10** alert triggered by perimeter drop thresholds.

### Detection
* **Incident ID:** `1787101253.39577`
* **Alert Timestamp:** Aug 19, 2026 @ 06:00:53.634
* **Wazuh Rule:** `87702` (Multiple pfSense firewall blocks events from same source)
* **Alert Level:** `10`
* **Source IP:** `192.168.20.10`
* **Destination IP:** `192.168.10.10`
* **Target Port:** `22` (TCP)
* **MITRE ATT&CK:** `T1110` (Brute Force) / `T1046` (Network Service Discovery)

### Triage & Investigation
* Verified security team operations; confirmed the activity was **unscheduled and unauthorized**.
* Identified rapid, high-frequency inbound connection attempts dropped at the firewall interface.
* Correlated firewall block events with concurrent Suricata protocol alerts.
* Assessed the potential impact as a port discovery scan or uncoordinated brute-force attempt targeting SSH.

### Classification & Escalation
* **Classification:** Suspicious Activity
* **Containment:** Monitored perimeter firewall drop enforcement.
* **Escalation:** Escalated to Tier 2 for further correlation and host-level compromise assessment.
* **Status:** Under Investigation
