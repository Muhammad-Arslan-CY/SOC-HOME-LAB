# SOC Operations Log — Day 1: Telemetry Pipeline & Foundation Setup

**Date:** August 21, 2026  
**Focus Area:** Host Firewall (UFW), NIDS Deployment (Suricata), and SIEM Decoding  
**Role Scope:** SOC Operations / Detection Engineering Foundations  

---

## 1. Operational Objectives
* Establish host-level and network-level telemetry pipelines on the Ubuntu workload.
* Resolve log pre-decoding and ingestion bottlenecks inside the Wazuh Manager container.
* Configure base detection for dropped ingress traffic.

---

## 2. Key Actions & Implemented Controls

* **UFW & Syslog Ingestion:**
  * Enabled UFW with a default deny ingress policy on the internal lab interface (`enp0s8`).
  * Identified pre-decoding classification failure in `wazuh-logtest` caused by ISO timestamps and generic `kernel` program headers.
  * Authored a child decoder (`ufw-kernel-child`) in `local_decoder.xml` to normalize key fields (`srcip`, `dstip`, `protocol`, `srcport`, `dstport`).

* **Initial SIEM Detection Rule:**
  * Created Rule `100010` (Level 5) in `local_rules.xml` to trigger alerts on `[UFW BLOCK]` events.
  * Mapped rule execution to MITRE ATT&CK **T1046 (Network Service Discovery)**.

* **Suricata NIDS Initialization:**
  * Installed Suricata 8.x and isolated monitoring to interface `enp0s8` (Subnet `192.168.10.0/24`).
  * Configured `HOME_NET` variables and verified EVE-JSON output pipelines.

---

## 3. Key Telemetry & Validation
* Verified log parsing through `wazuh-logtest` showing complete Phase 1, Phase 2, and Phase 3 alert generation.
* Validated initial network probes from Kali Linux (`192.168.10.20`) surfacing directly in Wazuh Security Events.
