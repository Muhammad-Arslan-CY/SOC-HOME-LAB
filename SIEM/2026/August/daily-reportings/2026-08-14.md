# Day 5 — pfSense Installation and Network Lab Setup

## Objective

Install and configure pfSense as a virtual network firewall and establish connectivity between the pfSense web interface and the Lab.

The goal for today was to reach a functional state where the pfSense web configurator and used now onwards in my Lab.

---

## Work Completed

### 1. pfSense Installation

* Installed pfSense as a new virtual machine.
* Configured the required virtual network interfaces for the lab environment.
* Completed the initial pfSense installation and boot process.
* Verified that pfSense successfully recognized its network interfaces.

### 2. Network Interface Configuration

* Worked through pfSense interface assignment and networking configuration.
* Configured the interfaces required for communication between the virtual machines.
* Verified the assigned pfSense IP address.
* Spent significant time troubleshooting the virtual networking configuration and ensuring the interfaces were operating on the intended networks.

### 3. Kali Linux Connectivity

* Used Kali Linux as the client system for accessing pfSense.
* Configured the network path between Kali and pfSense.
* Verified that Kali could reach the pfSense management interface.
* Investigated networking issues encountered during setup before reaching successful connectivity.

### 4. pfSense Web Interface

The final milestone for today was successfully accessing the pfSense web configurator from Kali:

```text
Kali Linux
    |
    | Browser request
    v
Firefox
    |
    | pfSense management IP
    v
pfSense Web Configurator
```

Firefox inside Kali can now be opened, the pfSense IP address can be entered, and the pfSense web interface loads successfully.

---

## Troubleshooting

A significant portion of the day was spent troubleshooting the networking configuration rather than simply installing pfSense.

The main focus was determining how the virtual network adapters, IP addressing, and VM network modes interacted with each other. The setup required identifying the correct network path between Kali and pfSense and ensuring the pfSense management interface was reachable from Kali.

This was an important practical exercise because the final web-interface access depended on the complete network path functioning correctly rather than only having pfSense successfully installed.

## Result

Today's primary objective was completed.

The pfSense virtual firewall is now installed and reachable from Kali through its web management interface. The lab has reached the point where pfSense can be used as an actual network security component for future firewall, routing, segmentation, monitoring, and security-testing exercises.
