## 2. Detection Engineering & Architecture

* **Suricata Custom Signature:**
  * Authored a threshold-based NIDS rule in `/var/lib/suricata/rules/local.rules` targeting high-frequency TCP SYN packets:
    `alert tcp $EXTERNAL_NET any -> $HOME_NET any (msg:"SOC Lab: High Volume SYN Flood Detected"; flags:S; threshold:type both, track by_src, count 100, seconds 2; sid:1000001; rev:1;)`

* **Wazuh Multi-Stage Rule Hierarchy:**
  * Ingested Suricata alerts via `ossec.conf` (`<location>/var/log/suricata/eve.json</location>`).
  * Created composite correlation rules in `local_rules.xml`:
    * Base Rule: Decodes Suricata alert signature ID `1000002`.
    * Escalation Rule (Level 15): Configured thresholds across a 5-second window.
  * Mapped alert directly to MITRE ATT&CK **T1498 (Direct Network Flood)**.

---

## 3. Attack Simulation & Validation
* **Vector:** Executed raw TCP SYN flood using `hping3 --flood -S -p --flood 192.168.10.10` from Kali Linux.
* **Result:** Suricata triggered signature `1000002` at line rate. Wazuh aggregated the burst, escalated severity, and fired **Level 15 Critical Incident Alerts** on the dashboard within seconds.
